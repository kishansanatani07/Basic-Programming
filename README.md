# Basic Programming

A structured collection of my programming practice problems, solutions, and study notes across **C**, **C++**, and **Python**.

## Repository Structure

| Language | Topics Covered | Index / Notes |
| :--- | :--- | :--- |
| **[C](./C)** | Input/Output, Operators, Conditionals, Loops, Arrays, Strings, Pointers, Functions, Recursion, Structures, Dynamic Memory, File Handling | [C Programs Index.pdf](./C/C%20Programs%20Index.pdf) |
| **[C++](./CPP)** | Basics, Conditionals, Loops, Patterns, Arrays & Matrices, Strings, Functions & Pointers, Recursion | [C++ Programs Index.pdf](./CPP/C++%20Programs%20Index.pdf) |

## Highlights

* **Topic-Wise Organization:** Programs are grouped by key programming concepts for quick reference and revision.
* **Program Indexes:** Dedicated PDF indexes in the C, C++, and Python folders make it easier to navigate solved questions.
* **Study Notes:** Concept explanations, dry runs, and handwritten-style notes are included to support learning and revision.

## How to Use

1. Browse any language folder (`C`, `CPP`, or `Python`) above.
2. Open the relevant **Programs Index PDF** to see the list of practice problems.
3. Click on any `.c`, `.cpp`, or `.py` file to view the source code.
4. Compile or run the code as needed using your preferred compiler or interpreter.

## Goals

This repository is meant to help with:

* practicing core programming fundamentals,
* revising important concepts across multiple languages,
* building confidence through consistent problem-solving.
